# First-Repo — To-do List

แอป To-do List อย่างง่าย สร้างด้วย React + Vite เก็บข้อมูลไว้ใน `localStorage`
ของเบราว์เซอร์ (ไม่มี backend)

## วิธีใช้งาน

```bash
npm install
npm run dev
```

แล้วเปิดลิงก์ที่ขึ้นในเทอร์มินัล (ปกติคือ http://localhost:5173)

## ฟีเจอร์

- เพิ่มงาน
- ติ๊กว่าทำเสร็จ / ยังไม่เสร็จ
- ลบงาน
- กรองดู: ทั้งหมด / ยังไม่เสร็จ / เสร็จแล้ว
- ข้อมูลถูกบันทึกไว้ในเบราว์เซอร์ เปิดใหม่ก็ยังอยู่
